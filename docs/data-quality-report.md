## Row funnel

Every row that **landed** is either kept or dropped for a named reason, and the two sum exactly to what landed.

Reconciling `rows_landed` against source record counts is an open gap, tracked in `docs/roadmap.md`. Every data loss found in this project so far has lived in exactly that blind spot.
