# `og-image.png` — provenance and regeneration

The social card served at `https://bikeshare.adnanreza.com/og-image.png` and
declared by `og:image` / `twitter:image` in `index.html`. Recorded here in the
form spec 002b established, because this project does not ship anything whose
origin it cannot state.

## What it is

`public/og-image.html` is the source composition; `public/og-image.png` is that
page rendered at exactly **1200 x 630**. The HTML is a build input, not a page
of the site — it carries `<meta name="robots" content="noindex">` and
`public/_headers` sends `X-Robots-Tag: noindex` for it as well.

Nothing in it is fetched at render time. The typeface is embedded as a `data:`
URI and the lockup is inline SVG, so the card composes identically offline, on
any machine, in any network.

## Assets used

| Asset | Origin | Terms |
| --- | --- | --- |
| Lockup (bicycle pictogram + 11-point maple leaf) | `public/logo.svg`, inlined verbatim apart from the two edits below | As recorded in `docs/features/002b-brand-identity.md`: bicycle is public domain (`PD-VzKat` / §5(1) UrhG); leaf is the National Flag of Canada's, used per Order in Council P.C. 1965-1623 s.4 with no exclusive rights claimed |
| Inter Tight Variable, latin subset (`inter-tight-latin-wght-normal.woff2`) | `node_modules/@fontsource-variable/inter-tight`, the same package `src/main.tsx` loads for the site | SIL Open Font License 1.1 (see the package's `LICENSE`). Embedding is permitted; the font is not sold and carries no reserved font name |
| Colours | `src/index.css` light tokens, verbatim: paper `#f7f9fb`, ink `#090e11`, muted `#636a6f`, rule `#d4d8db`, and the three series hues `#196ea9` / `#0f766e` / `#a16207` | Project's own |

Two edits are applied to the logo when it is inlined, both in the generator:

- its `prefers-color-scheme: dark` rule is **removed**. It repaints the bicycle
  `#ededed`, which on this card's paper background would render the pictogram
  invisible whenever the rendering browser happened to be in dark mode — a
  property of the machine doing the screenshot, silently baked into a PNG;
- its `role="img"` / `aria-label` are dropped, since the card is a single image
  and the alt text lives in `og:image:alt`.

## What it deliberately does not contain

**No figure from the data.** A number baked into a PNG cannot be regenerated by
the pipeline that owns it, and the site's rule is that copy derives from the
data window rather than remembering it (`docs/decisions.md`, 2026-07-29 — "a
number in prose needs a query, not a memory"). The card carries the name, the
tagline, and the three cities, all of which are stable facts of the project.

## How to regenerate

**The HTML** (only needed if the font package, the logo or the composition
changes) — the generator, run from the repository root:

```bash
node scripts/make-og-image.mjs
```

**The PNG** — render the HTML in a **headed** browser at exactly 1200 x 630 and
save the result to `public/og-image.png`. Headed, not headless, for the reason
`docs/decisions.md` (2026-07-29) records: a throttled or backgrounded tab can
report success while having painted nothing, and this is an image whose only
acceptance test is that it looks right. With Chrome:

```bash
open -a "Google Chrome" public/og-image.html   # then screenshot the 1200x630 card
```

or, driven from a devtools/CDP session, set the viewport to 1200 x 630 with
`deviceScaleFactor: 1` and capture the full page.

`src/og-image.test.ts` reads the PNG's IHDR chunk and fails if the file is
missing or is not 1200 x 630 — so a card that was never regenerated cannot ship
quietly.
